# GBIC @ UC San Diego

https://gbic-at-ucsd.web.app

Our website's subdomain is hosted through Firebase. To edit the source code, please create a pull request. Github Actions will create a draft URL (through Firebase) that can be used to preview your changes prior to merging: https://firebase.google.com/docs/hosting/github-integration

To use the `firebase` CLI tool, you can simply press comma "," to load our pre-configured GitHub Devcontainer.
